# AXIS Portfolio

موقع عرض أعمال ثابت (HTML/CSS/JS) — بلا خادم ولا قاعدة بيانات ولا لوحة تحكم.

- **النشر:** الملفات تُخدَّم كما هي من Caddy على نطاق فرعي.
- **تعديل المحتوى:** من لوحة إدارة المتجر ← «موقع عرض الأعمال». الموقع يحمّل المحتوى
  المنشور من المتجر عند كل فتح (`loader.js`)، ويعمل بنصوصه الافتراضية إن تعذّر الوصول.
- **الحقول القابلة للتعديل:** `schema.js`، مولَّد من `index.html`. بعد أي تعديل على نصوص
  الصفحة أو بنيتها: `pip install beautifulsoup4` ثم `python tools/build_schema.py`.
- **عنوان المتجر:** `config.js` (فارغ = النطاق الأب تلقائياً).
